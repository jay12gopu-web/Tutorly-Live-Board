==================================================
TWO TEACHING MODES
==================================================

Add:

SHOW ME

Tutorly demonstrates the next step on the board.

Example:

Tutorly:
“First draw a ray AB.”

The board automatically draws it.

LET ME TRY

Tutorly gives the instruction but waits for the student to draw it.

Example:

Tutorly:
“Now draw an arc with A as the centre.”

Student draws it.

Then mock Tutorly checks the action and responds.

No real AI is required yet.

==================================================
STRUCTURED AI BOARD COMMANDS
==================================================

THIS IS VERY IMPORTANT.

Create a reusable JavaScript board command engine.

Later Tutorly’s AI should be able to control the board using structured JSON commands.

Example:

{
  "action": "draw_line",
  "id": "AB",
  "from": {"x": 180, "y": 320},
  "to": {"x": 620, "y": 320},
  "label": "AB"
}

Support commands such as:

draw_point
draw_line
draw_ray
draw_arrow
draw_circle
draw_arc
draw_rectangle
draw_text
draw_axes
draw_graph
highlight
move_object
delete_object
clear_board
zoom_to

Create something similar to:

BoardCommandEngine.execute(command)

Do not hardcode AI drawing directly into button handlers.

==================================================
DEMO LESSON
==================================================

Include one working demo:

“Construct an Angle Bisector”

Steps:

1. Draw base angle / rays.
2. Draw an arc from the vertex.
3. Mark intersection points.
4. Draw arcs from those points.
5. Mark their intersection.
6. Draw the bisector.

The user should be able to switch between:

Show me
and
Let me try

during the lesson.

This is important because later Tutorly needs to understand what the student changed.
